# SẮC Studio

Trang web bán hàng thời trang phong cách **Bold Retro-Modernism** — HTML, CSS và JavaScript thuần, không cần build.

## Tính năng
- Hero, danh mục, lưới sản phẩm với lọc / sắp xếp / tìm kiếm
- Xem nhanh sản phẩm: chọn màu, size, số lượng
- Giỏ hàng & danh sách yêu thích (lưu trong trình duyệt)
- Flash sale đếm ngược, lookbook, đánh giá, đăng ký bản tin
- Responsive cho điện thoại

## Chạy thử
```bash
python3 -m http.server 5173
```
Mở http://localhost:5173

Sản phẩm được khai báo trong mảng `PRODUCTS` ở `app.js`. Ảnh minh họa từ Unsplash.
